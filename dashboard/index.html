Defensive Q&A For Reviewers:

Q: "Why are you using WESAD replay instead of live ESP32 sensors?"

"Our current implementation uses the clinical WESAD benchmark to validate the complete algorithmic pipeline under controlled laboratory stress conditions (TSST protocol). Because acute psychological stress cannot be safely or ethically induced ad-hoc during a 5-minute academic review, prerecorded clinical replay allows us to demonstrate verified stress transitions against known medical ground truth. Our pipeline is 100% dual-mode: if an ESP32 is connected via USB, it automatically switches to live physical acquisition."

Q: "Why does ST-GCN beat standard 1D-CNN?"

"Standard 1D-CNN applies parallel 1D filters independently across channels, failing to capture how channels interact. ST-GCN computes a dynamic Pearson correlation matrix every 3 seconds: when stress triggers simultaneous tachycardia and vasoconstriction, the graph edge weights strengthen, allowing the spatial GCN layer to propagate cross-modal features. This yields a +13.88% higher Stress F1 on clinical test subjects."

Network Architecture Specifications

Designed for extreme edge efficiency: 6,466 parameters, 73.8 KB ONNX binary, 2.57 ms CPU latency.

Stage / Layer Operation & Description Output Tensor Shape
Input Window 3 synchronized channels (ECG, PPG, Temp) @ 128 Hz (3.0s window) (B, 3, 384)
Graph Construction Dynamic Pearson Correlation Adjacency A = |corr(x)| + I (B, 3, 3)
Spatial Conv 1 ManualGCNConv (1 in-feat → 32 hidden, ReLU) (B, 384, 3, 32)
Spatial Conv 2 ManualGCNConv (32 hidden → 32 hidden, ReLU) (B, 384, 3, 32)

Global Pooling Global Node Mean Pooling over V=3 nodes (B, 64)
Classification Head Linear(64 → 2) + Softmax (Calm vs Acute Stress) (B, 2)
